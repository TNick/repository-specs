# React Vite UI

Use this building block for a browser application built with React and Vite.

## Required

- Keep the Vite app entry point, routes, shared components, and feature code
  in explicit directories.
- Use relative API paths by default and configure development proxying rather
  than scattering hostnames through application code.
- Test user-visible behavior with Testing Library and Vitest.
- Keep browser automation in a separate end-to-end test tree.
- Make loading, error, empty, and accessibility states explicit.

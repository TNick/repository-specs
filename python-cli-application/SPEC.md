# Python CLI Application

Use this profile when the primary user interface is a Python command-line
program.

## Required

- Expose commands through a declared console entry point.
- Keep parsing, validation, business operations, and output formatting in
  separate testable modules.
- Return useful exit codes and write diagnostics to logging or stderr.
- Provide help text and examples for every principal command.
- Test command behavior through direct unit tests and representative CLI
  invocations.

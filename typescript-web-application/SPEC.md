# TypeScript Web Application

Use this profile for a browser-first TypeScript application, whether it is a
single app or one member of a workspace.

## Required

- Keep routing, API access, features, shared UI, and styling in explicit
  boundaries.
- Keep user-visible strings and environment-dependent URLs configurable.
- Test routes and components through observable behavior.
- Build the production bundle and typecheck it in CI.
- Add `typescript-library-workspace` when the repository also publishes
  reusable packages.
